# 用量同步（Dosage Sync）· 操作手册

> 关联文档：[设计方案](方案.md) · [README](../README.md)

## 1. 环境准备（开发构建）

| 依赖 | 版本要求 | 说明 |
|---|---|---|
| Node.js | ≥ 18 | 前端构建与 electron-builder 打包 |
| npm | 随 Node | 包管理 |

> 无需安装 Rust / WebView2 / Visual Studio：Electron 自带 Chromium 运行时，后端为纯 JS/TS（Node），本地 SQLite 用 Node 22 内置 `node:sqlite`，无原生编译依赖。

## 2. 构建与打包（安装包 + 便携版）

```bash
# 安装依赖
npm install

# 开发调试（Vite + Electron 热更新窗口）
npm run dev

# 打包发布（NSIS 安装包 + portable 便携版）
npm run electron:build
```

产物位置：

- 安装包：`release/DosageSync Setup <版本>.exe`
- **便携版**：`release/DosageSync-<版本>-portable.exe`（单文件，双击即用；数据默认在用户主目录 `~/.Dosage_sync/`，可在设置页自定义；便携版不支持开机自启——注册的会是临时解压副本，退出即失效）。

> 图标已生成在 `build/`（icon.ico / icon.png / tray.png），无需额外步骤。

### 2.1 仅预览前端 UI（无需 Electron）

前端已内置浏览器 mock，可脱离 Node 后端独立预览界面与交互：

```bash
npm install
npm run dev:web       # 浏览器打开 http://localhost:1420
```

或直接双击打开仓库根 `preview.html`（零依赖静态原型，效果一致）。

## 3. 首次配置

首次启动默认进入总览页，可从设置完成配置（无引导向导）：

1. **WebDAV 配置**：填写地址、账号、密码、根目录 → 点「测试连接」。
2. **电脑命名**：给本机起个可读名字（如"公司笔记本"）。
3. **数据源探测**：应用自动探测 `~/.zcode`、`~/.codex`、`~/.dsh`、`~/.workbuddy`、`%APPDATA%/reasonix`（或 `~/.reasonix`）、`~/.gemini/antigravity`、`~/.gemini/antigravity-ide`；每行会显示目录是否可读取，也可点「重新探测」。
4. **启用数据源**：ZCode 与 WorkBuddy 默认启用；Codex、DeepSeek Harness、Antigravity 与 Antigravity IDE 默认停用，请按需打开右侧开关。
5. **保存后**：手动点「立即同步」执行已启用源的首次全量同步。

## 4. 配置 WebDAV（飞牛 fnOS）

1. 登录飞牛 fnOS 控制台 → 「文件管理 / 远程挂载」或「WebDAV 服务」开启 WebDAV。
2. 记下 WebDAV 地址，通常形如：`http://<fnOS-IP>:<端口>/dav`（具体以 fnOS 界面显示为准）。
3. 在工具中填写：
   - **地址**：上述地址（去掉末尾多余路径）。
   - **账号 / 密码**：fnOS 登录账号密码，或专为 WebDAV 创建的账号。
   - **根目录**：留空则写入 `/usage-tracker`；或指定一个子目录如 `/dosage-sync`。
4. 点「测试连接」，成功后方可保存。

> 其它服务（Nextcloud / 坚果云 / 群晖）在「存储预设」下拉切换，路径编码与兼容参数自动适配；未列出的选「自定义」。

## 5. 日常使用

- **同步**：托盘菜单「立即同步」；或主界面「同步」按钮，观察分段进度条（抽取 → 上传 → 拉取 → 合并），可随时点「取消」安全中断。
- **同步弹窗**：点击顶部「立即同步」后会显示阶段进度与实时日志，包含本地获取、解析、压缩、WebDAV 上传、其它电脑下载、解压合并等步骤。
- **调度**：设置页选「每小时」或「每天固定时间」（如 23:30）；固定时间同步具备补跑机制，错过设定时刻（睡眠/关机）后，开机当天会自动补跑一次。
- **主题**：设置页切换深色 / 浅色。
- **筛选**：主界面按时间（日/周/月/年/自定义）、设备、软件、模型、供应商筛选。
- **明细页日期筛选**：「用量明细」页可按开始/结束日期筛选记录（配合模型/供应商/设备/状态）；「导出 CSV / JSON」会带上当前全部筛选条件与日期范围，设置页的导出按钮仍为全量导出。热力图点开某天弹窗后，即可到明细页按该日期查看分项。
- **删除退役设备**：某台电脑淘汰后，在侧边栏「设备」中将鼠标悬停到该设备上会显示「×」删除按钮——点击确认后同时删除 WebDAV 上的该设备数据与本地记录（不可恢复；本机设备不可删除）。删除后其他设备不再拉取该设备的数据。
- **软件源切换**：顶部可在「全部」与 ZCode、Codex、DeepSeek Harness、WorkBuddy、Reasonix 等源间切换，进入总览默认选中「全部」；圆点表示该源已启用（「全部」的圆点表示任一可见源已启用）。「全部」展示所有源数据累加的总和（页面结构不变，为各分类汇总视图）；单源时总览、设备列表、趋势、热力图和用量明细只展示当前源，切换时会自动清除设备筛选。分类按钮位于「全部」右侧的横向滚动盒内，按钮较多时可左右滑动，「全部」始终固定在盒子左侧外可见，不会与右侧同步区重叠。
- **设备筛选**：侧边栏「设备」下点击某台电脑，总览、趋势、热力图与设备构成即切换为只看该电脑（点击即选中，不会因再点一次而误取消）；点「全部电脑」或顶部筛选横幅的「查看全部电脑汇总」恢复全量。切换设备时若数据查询失败，顶部会显示红色错误横幅并保留旧数据，可点「重试」。
- **图表**：曲线图看趋势，热力点阵图看每日用量，点击某天看明细；趋势图自动补齐无数据日期的零点，最右侧严格对应今天，默认选中「近七天」（左侧依次为近七天 / 月 / 季 / 半年 / 年，切设备后保持所选范围）。热力图展示滚动的一年窗口（今天起往前 365 天，月份随窗口循环、不从 1 月固定开始），只画到今天的日期、默认定位到最右侧（今天），顶部月份标签每月只出现一次并精确对齐当月首列；鼠标悬停立即显示日期与用量的悬浮看板（即时跟随，无系统延迟）。
- **总览 KPI**：左上角依次展示总计消耗 Token、今日消耗 Token、总计缓存命中率、今日缓存命中率、总计调用次数、今日调用次数（「今日」均按当天 0 点起累计）；页面不再显示「完整口径」字样（统计口径选择仍保留在设置页）。
- **模型趋势**：趋势图顶部提供「汇总 / 按模型」切换——「汇总」仅显示总量曲线（默认，图例干净）；「按模型」按模型显示独立彩色曲线和可滚动图例，所选范围内无 token 用量的模型不会显示曲线。
- 趋势范围切换会重新查询对应范围，旧请求不会覆盖最新选择。
- 总览下方显示完整 15 级 token 热力图与用量构成卡片，WebDAV 同步会实际执行远端目录创建和文件上传。
- **403 错误**：若提示服务器拒绝写入，请检查 WebDAV 账号写权限和配置的根目录；应用会停止本次同步并在弹窗、日志中保留失败阶段。
- **测试连接**：保存前可先测试 WebDAV 连通性；若地址使用 `http://`，测试成功时会额外提示「账号密码将明文传输，建议改用 https」。
- **设备 ID 告警**：同步日志中出现「设备 ID 疑似被多台电脑同时使用」时，说明同一设备标识有多台电脑在写 WebDAV（多为整机克隆/复制数据目录导致），双方日分片会互相覆盖，请为其中一台清除本地数据目录重新生成设备 ID；若你最近迁移过数据目录，该告警可忽略。
- **保存设置**：点击保存后会显示成功或失败提示；保存失败不会清空已填写内容。

本软件由 **沐辉玄制作**。
- **统计口径**：总量默认按「输入 + 输出 + 推理」统计，设置页可切「简洁口径（输入 + 输出）」；输入拆分为「净新增输入 + 缓存命中」，缓存命中率 = 缓存命中 / 总输入。四源的「输入」均包含缓存命中（ZCode 原生口径、DSH 适配器归一化补入、Codex 经本机 rollout 数据实测确认、WorkBuddy 会话转录实测同口径），命中率跨源可直接对比且恒 ≤ 100%；DSH 的缓存写入仍作为独立分项。
- **调用次数**：ZCode、Codex、WorkBuddy 按单次用量记录计；DSH 按 `session_rollups` 日聚合行数计，一行算一次，不使用其 `requests` 值。
- **WorkBuddy**：读取 `~/.workbuddy/projects/` 下会话转录中的逐次 token 用量（含 Auto 路由后的真实模型名）；推理与缓存写入 token 从其原始回包补入，源数据缺失时记 0。转录中的对话内容不会被读取或上传。
- **Reasonix**：读取 `stats/YYYY-MM-DD.jsonl` 每日账本（目录默认 `%APPDATA%/reasonix`，macOS/Linux 为 `~/.reasonix`，可用 `REASONIX_STATE_HOME` / `REASONIX_HOME` 覆盖）。账本把输入拆成互斥的 `cache_miss`/`cache_hit`，适配器归一化为「输入含缓存」口径后入库；`turn: true` 的轮次行不计费、已跳过；账本不记录缓存写入，该项记 0（费用轻微低估）。只读取 token、模型与时间字段，不涉及任何对话内容。
- **Antigravity / Antigravity IDE**：两者本地无 token 明细文件，统计采用配额余额快照法——每次同步读取本地语言服务的配额已用量（可分模型），按两次快照差值生成记录，**单位为配额点数而非 token**；需软件正在运行才能读取，未运行时跳过并写日志；首次同步只建立基线，配额周期重置后自动从 0 重新累计。
- **导出**：设置页导出全部明细；「用量明细」页导出当前筛选范围的明细。
- **同步性能**：分片上传/下载按内容哈希增量执行——内容未变化的日分片自动跳过传输，多设备长期使用时同步耗时不随历史线性增长。
- **托盘**：右键查看今日用量、立即同步、打开界面、退出。系统通知默认只在同步失败时弹出，设置页可开启「同步成功也通知」。

## 6. 双电脑同步

1. 电脑 A：完成配置，上传本机用量到 WebDAV。
2. 电脑 B：完成配置（相同 WebDAV、不同电脑名），自动拉取 A 的用量并上传自己的。
3. 任一台的界面会同时显示 A、B 各自用量与总量；各自只上传自己的数据，互不覆盖。

## 7. 常见问题（FAQ）

| 现象 | 处理 |
|---|---|
| 连接测试失败 | 核对地址/账号/密码；确认飞牛 WebDAV 已开启；路径是否有特殊字符 |
| 同步报 401 | 账号密码错误或该账号无 WebDAV 权限 |
| 探测不到数据源 | 确认对应软件至少运行过一次，并检查 `~/.zcode`、`~/.codex`、`~/.dsh`、`~/.workbuddy` 或 `~/.gemini/antigravity(-ide)` 是否存在且可读 |
| Codex / DSH / Antigravity 无数据显示 | 在设置页开启对应数据源并保存，然后执行一次「立即同步」；Antigravity 系还需软件正在运行（配额经本地语言服务读取），且首次同步只建基线、第二次起才出数字 |
| 断网 | 记录进离线队列，恢复后自动补传 |
| 重复计数 | 不会——按 `设备ID+源记录ID` 幂等去重 |

## 8. 数据与备份

| 内容 | 位置 |
|---|---|
| 本机汇总库 / 配置 | 默认 `~/.Dosage_sync/`（即 `C:\Users\<用户名>\.Dosage_sync`，可在设置页自定义，重启后生效） |
| ZCode / Codex / DSH 源数据 | `~/.zcode` / `~/.codex` / `~/.dsh`（应用只读） |
| Antigravity 源数据 | `~/.gemini/antigravity` 与 `%APPDATA%/Antigravity`（应用只读） |
| Antigravity IDE 源数据 | `~/.gemini/antigravity-ide` 与 `%APPDATA%/Antigravity IDE`（应用只读） |
| WebDAV 云端数据 | `<根目录>/usage-tracker/` |
| 同步日志 | 设置页「查看日志」 |

云端 `usage-tracker/` 是全部电脑的汇总来源，建议在飞牛上对该目录做定期快照备份。
